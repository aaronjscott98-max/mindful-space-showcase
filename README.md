# Mindful Space — Development Log

For now, this README will serve as a development log documenting the work I have completed throughout the project. Once the project is finished, I plan to update the README to match the structure and presentation of my other GitHub repositories.

## Project Background

This project originates from my honours work, which was officially marked and graded back in 2023. To be completely clear, this revamped version is a personal initiative and is not intended to alter or replace that original academic grading in any way.

Instead, I decided to return to the project three years later to breathe some new life into it with fresh design changes, improved functionality and a working website. My goal is to give the original concept an upgraded feel while seeing just how far I have come as a designer and developer since graduating.

Now officially titled **Mindful Space**, a name that I feel is appropriate for this type of serious subject matter, the original project focused on raising awareness of anxiety and depression among university students during COVID-19. It also explored the impact of the cost-of-living crisis on students balancing employment, coursework and their personal lives.

This evolved version will build on that foundation, with plans to carry out additional research to explore what has changed since the original project and whether the challenges students face today have improved or become more difficult.

## Development Log

### Week 1 — Landing Page
**Technologies: HTML, CSS**

For the first week, I focused on developing the main layout of the landing page and adding content that would typically be found on a website focused on mental health awareness.

My main priority was establishing the overall layout, navigation and visual direction of Mindful Space while ensuring the design was appropriate for the subject matter.

I also implemented interactive buttons and navigation elements throughout the page. However, at this stage, several of these acted as placeholders, as the remaining pages had not yet been developed.

My next step was to begin working on the Services section before returning to the landing page to refine the navigation and implement the Services dropdown menu.

### Week 2 — About Page & Game Development
**Technologies: HTML, CSS, JavaScript**

For the second week, I started by developing the About page before deciding to focus on the game itself.

I began by creating the main game page and then moved on to implementing the JavaScript functionality, getting the core gameplay mechanics working before introducing additional visual assets.

These assets included the playable character, thought bubbles, platforms and city backgrounds, helping to give the game its own visual identity while maintaining consistency with the rest of the website.

The game consists of three levels, with players progressing through platform-based challenges while collecting thought bubbles. Upon completing the game, players are presented with a motivational quote intended to reinforce the mental health awareness theme behind Mindful Space.

Although the core gameplay was functional, there were still areas that required further attention, including the links displayed at the end of the game, improvements to the CSS, responsive layouts and general functionality.

I originally planned to address these during a later development stage before gathering feedback and making any necessary changes.

### Latest Update — Returning to Mindful Space After Four Months
**Technologies: HTML, CSS, JavaScript**

After taking a four-month break from Mindful Space due to personal circumstances, I decided to return to the project and continue where I had left off.

Rather than immediately introducing major new features or redesigning the website, my main focus was on reviewing the existing code, cleaning up areas that needed attention and fixing issues that I had either previously overlooked or left unfinished.

I started by revisiting the HTML, CSS and JavaScript, reviewing the overall structure of the website and identifying areas where the functionality and user experience could be improved.

**Website Improvements**

- Reviewed and cleaned up the existing HTML, CSS and JavaScript.
- Fixed navigation issues and corrected previously incomplete links.
- Improved the Services dropdown menu to work more consistently across desktop and mobile devices.
- Refined the dropdown styling to give it a cleaner appearance.
- Improved responsive layouts across different screen sizes.
- Made improvements to accessibility and general usability.
- Added and connected additional informational and support pages.

**Game Improvements**

Alongside the website improvements, I also returned to the JavaScript responsible for the game's mechanics.

One of the main issues I wanted to address was the overall difficulty. The original version was relatively straightforward, with limited variation between playthroughs.

To improve this, I made several changes to introduce more challenging and unpredictable gameplay.

- Introduced mobile touch controls, allowing the game to be played on smartphones.
- Improved the game's responsiveness in both portrait and landscape orientations.
- Increased the overall difficulty across all three levels.
- Implemented random platform generation, meaning platforms appear in different positions during each playthrough.
- Adjusted platform widths, heights and spacing to make jumping more challenging.
- Added additional platforms and alternative routes to introduce more variety.
- Reduced the number of thought bubbles spawning throughout the levels.
- Refined the checkpoint system to make progression more challenging.
- Improved the pause, resume and restart functionality.
- Added a wider selection of motivational quotes, with a different quote displayed at the end of each completed playthrough until the selection has been used.

An important part of improving the platform generation was ensuring that the randomly generated layouts remained achievable. Although the difficulty has increased significantly, the main routes are designed around the character's jumping capabilities to avoid creating impossible jumps.

I also spent time reviewing the game on different screen sizes to ensure that the updated mechanics and mobile controls worked alongside the existing desktop experience.

Although much of this update focused on code maintenance, bug fixes and gameplay refinements rather than developing entirely new features, it gave me an opportunity to revisit my earlier work with a fresh perspective.

Returning to the project after four months also reminded me of the importance of reviewing previous design and development decisions, particularly when there are opportunities to improve the overall experience.

## Next Steps — User Testing & Further Research

With the main website functionality and gameplay improvements now in place, my next priority is to begin gathering user feedback.

I plan to carry out user testing to understand how people interact with Mindful Space, particularly the website navigation, accessibility, mobile experience and overall game difficulty.

This will help me identify any remaining usability issues and determine whether further changes are needed.

I also intend to revisit the research behind my original honours project to explore how student mental health has changed since 2023, particularly in relation to anxiety, depression, academic pressures and the cost of living.

The aim is to build on the original research rather than simply reuse it, allowing the revised project to reflect more recent experiences and challenges.

Once these stages are complete, I plan to update this README into a more comprehensive project overview, similar to my other GitHub repositories. This will include the project's purpose, technologies, key features, development process, challenges, improvements and any findings from user testing.

Ultimately, Mindful Space is an opportunity to revisit a project that played an important part in my university experience and demonstrate how my design and development skills have progressed since completing my honours work.
