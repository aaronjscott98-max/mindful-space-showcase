What this version does

This static project does not include user accounts, a contact form, advertising scripts, analytics, or game data uploads. The game runs in your browser, and score progress is not saved to a server.

Some pages contain links to external mental health organisations. Their own privacy notices apply when you follow those links.

Hosting

The hosting provider may process technical information such as IP addresses and access logs. Review the provider’s policies if you deploy this project publicly. This notice should be updated if analytics, forms or other services are introduced.
